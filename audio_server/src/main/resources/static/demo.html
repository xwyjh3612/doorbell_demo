开始演示

  1. 给 ESP32 与 4G 模块供电，插好可联网的 SIM 卡。
  2. 打开 App，等待“服务已连接”，保持通话页面打开。
  3. 手机点“呼叫设备”后，在设备端接听；设备主动呼叫时，在 App 点“接听来电”。

默认设备：189833342344184
同一接听端 ID 同时使用一个客户端。

此版用于前台现场演示：离开 App 会结束通话，暂未加入后台或锁屏来电通知。服务连接成功表示信令已连通，设备在线与实际声音需通过设备通话确认。
