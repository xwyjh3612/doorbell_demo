# V3工程复核用Gerber及钻孔

这些文件从当前保存PCB导出，用于厂家DFM和工艺复核，**尚未生产放行**。不能把DRC 0当作实际电源、模组封装或整机验收。

- 100×75mm、1.6mm四层；外层1oz、内层0.5oz。指定叠层、RF/USB阻抗需要厂家复核。
- PTH / NPTH分别导出；圆口有3个G85槽孔，不能当作普通圆孔。
- 最小钻孔0.2mm。In1为参考地，In2含电源与信号。
- 默认SMT、插件和不贴器件按cost/assembly-bom.csv；SMT坐标按cost/positions.csv，KiCad原点及底层旋转需在贴装导入后核对。
- ML307内部焊盘、钢网、实物模组型号和连接器封装仍需厂商装配复核。
- 电源满载/峰值、4.5V边界、启动、温升与UPS切换未完成实际首板验收。完整清单见工程目录的《工程复核及首板验收.md》。
