# 50元量产主板目标

2026-11-22。按1000台口径，将包含ESP32-S3、4G、音频电路和板载UPS的已装配主板目标设为50元/台。不含外置电池及NTC、喇叭、雷达、外壳、适配器及运费。首批5台的开发、工程和起订费用不能用此量产目标倒推。

**目前未达到，不能作为已验证成本或承诺报价。** 当前四层载板物料72.8068元/片；加PCB和加工89.0528元/片；加外挂ESP32/音频模块、线束及插接烧录验收123.0528元/片，均按现有预算口径。仅将裸PCB改成双层不能降到50元。

## 必须改变的设计

1. 新设计直接集成ESP32-S3模块和音频电路，替代完整开发板、音频外挂模块和大量线束。不能仅复制当前载板。
2. 优先双层、常规孔径和单面SMT；尺寸按实际集成布局及外壳约束复核。现有内层布线不能直接删除。
3. 重新选完整供电方案。现有C8/C9合计10.46元、U6 9.01元，仅这三件19.47元；应做可替代性和环路/瞬态验证后更新原理图和封装，不可只改价格。预留UPS接口不等于已经包含可工作的UPS。
4. 保留已有协议、PSRAM需求、UART电平转换、RF/SIM、调试刷机、按钮和可选雷达接口；按实际装配BOM计算。

如果上述器件采购或电源验证无法满足预算，应明确报告差额并调整方案，不能标记50元已实现。主板定版、真实BOM报价和新板实机验收全部完成后，才能回答最终是否达标。
