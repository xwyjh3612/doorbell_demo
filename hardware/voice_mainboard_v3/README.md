# 语音对讲V3主板工程

本版已完成可编辑的KiCad 9原理图、100×75mm四层PCB及实际装配BOM。独立检查通过：**ERC 0、DRC 0、未连接0，490项引脚/网络映射与原理图、PCB一致**。这是首板工程复核版本，尚未完成电源、封装、装配与整机验收，尚未生产放行。

板上直接焊ML307R-DL，集成充电、备用升压、自动电源切换、欠压控制和电池采样。ESP32-S3、INMP441、MAX98357沿用完整模块，通过线束连接。本版费用已经将这些外挂模块单独计入“主板总成”；当前架构还没有达到80元整机目标。

## 供电与UPS

```text
4.5～5.5V圆口 -> F1 -> Q6 -> VIN_PROTECTED -> TPS2117 VIN1
受保护1S电池 -> TPS61230A约4.992V -> TPS2117 VIN2
TPS2117 -> JP4 2-3 -> POWER_BUS
POWER_BUS -> TPS62933P约3.792V -> J19 1-2 -> ML307 VBAT
POWER_BUS -> TPS63061固定5V -> JP1 1-2 -> SYS_5V
SYS_5V -> JP3 1-2 -> ESP32；另供功放和可选雷达
VIN_PROTECTED -> TP4056 100mA -> 受保护1S电池
```

输入为5.5mm外径/2.5mm中心的圆口，中心正极，标称5V/2A。F1为4A PTC，选该额定值用于温度降额余量，整机适配器基准仍是2A。Q6采用在低栅压有明确导通电阻规格的DMP2035U；ML307裸模组始终使用约3.8V支路。

就近备用升压输入去耦为C41，C40另作输入储能。已测保存PCB的局部走线路径并计算条件功率预算。5V/2A不足以承诺模组2A、系统350mA及100mA充电的同时持续满载；4.5V输入下的模组稳压余量也未通过实测。标称电源和瞬时模组电流是不同定义，不能以2A适配器直接替代负载/瞬态验证。

普通单节4.2V满充锂电池包接J2，包内应有独立保护，放电能力至少5A，10k/B3950 NTC接J4。主板提供正常工作欠压滞回及充电温度检测；电池包保护和NTC随外置电池采购。100mA默认充电减少通话期间额外输入负载，GPIO38预留关闭充电，现有固件尚未驱动该功能。

硬件欠压标称约3.14V关闭升压、3.78V恢复。外电优先控制标称约3.98V切出、4.03V切回。比较器为LM393LV，基准为TLV431B；控制网络已跑行为SPICE和电阻容差角落计算，未代表开关电源或完整UPS通过。

## 默认跳线及接口

每个三针电源选择位只安装一个跳帽：JP4 **2-3**为板载UPS正常模式，JP1 **1-2**为系统5V，J19 **1-2**为板载3.8V，JP3 **1-2**为系统给ESP32供电。JP2短接后为雷达供电，基础款可拔掉。

| 接口 | 针序 | 用途 |
|---|---|---|
| J18 ESP32四针TTL | 1 GND，2 TX43，3 RX44，4 5V | TTL RX接TX43、TTL TX接RX44；串口逻辑3.3V |
| J2 电池 | 1 BAT+，2 GND | 受保护单节4.2V体系电池包 |
| J4 温度 | 1 NTC，2 GND | 电池包10k/B3950 NTC |
| J16 可选雷达 | 1 5V，2 GND，3 GPIO6，4 GPIO8 | 雷达TX接GPIO6，雷达RX接GPIO8 |
| J14 INMP441模块 | 3.3V/GND/BCLK14/WS13/DATA12 | 保留现有已调通的音频引脚 |
| J15 MAX98357模块 | 5V/GND/BCLK15/WS16/DATA7 | 功放板与扬声器输出接法沿用现有模块 |
| J17 外部呼叫按钮 | GPIO0/GND | 常开按钮；SW1同时为BOOT/呼叫 |
| J19 模组电源选择 | 1板载3.8V，2模组VBAT，3外部3.8V | 用于分支隔离和返修 |
| J20 外部模组供电 | 3.8V/GND | 可单独验证模组支路 |
| J22 USB Host预留 | GND/D+GPIO20/D−GPIO19 | 默认DNP，后续选装验证 |

J13是2×15信号线束接口，针序在原理图和design.json中，不能直接套接未知型号开发板。GPIO2预留电池ADC、GPIO9控制采样开关；开启后建议等待60ms再取样，比例2.5，电量只作估算。电池采样、充电抑制、GPIO11/21模组开机/复位驱动尚未集成到当前业务固件；首板先通过J6按模组手册进行手动开机验证。

四针TTL采用手动BOOT/RESET进下载方式。正常用主电供电并只接TTL的GND/TX/RX；JP3用于选择TTL供电给ESP32支路。SW2复位ESP32开发板EN。

## 当前AT与USB预留

默认R26/R27/R30贴装，R28/R29/R31/J22不贴，ML307 USB供电脑维修使用。Host选装时两组选装料互换，避免双主机或VBUS源并接。USB的VBUS只作模组检测，不是VBAT主电源。

官方ESP WebRTC协议和组件、当前业务固件及主动丢旧包策略没有因本次画板而更改。PCB中的USB通路是后续实验接口，当前40轮使用UART AT。

## 板层与制造复核

1.6mm四层：F.Cu/B.Cu各1oz，内层各0.5oz；In1为连续参考地，信号和电源不在该层切割回流。当前设计外层到参考层介质0.18mm，中心介质1.135mm，介电常数4.2是计算输入。实际生产叠层及RF约50Ω、USB约90Ω需与板厂确认后复核。

最小线宽/间距0.2mm；U11同一封装相邻焊盘按厂家DGK形状使用0.15mm例外，走线规则仍保持0.2mm。现有21个过孔采用0.45/0.2mm，其余主要为0.6/0.3mm。试将小孔扩大到0.3mm会发生间距冲突，当前工程保留原孔，并按0.2mm工艺计算板费。

原理图更新使用generate_schematic.py，独立校验使用verify_design.py。build_bom.py读取保存的PCB与已记录公开物料参考，build_cost.py读取实际数量加工计算记录。生成早期摆放的generate_integrated属于搭建过程，运行会替换手工布线；当前工程以保存的kicad_pcb为准。

最后一次装配分类修正后，加工费按原有公开数量费率调整估算，旧响应与调整参数均保留；当前修正参数未获得新的公开响应，不当作厂家最新报价。derive_processing_budget.py保留该预算依据和假设，正式生产费用仍需完整BOM/DFM核价。

工程包不含早期失败的过孔/去耦位置探查PCB。package-manifest.json列出每个交付文件的SHA256；package_review.py按明确清单打包，避免将中间错误报告误认为最终结果。导出的fabrication-unreleased只用于DFM复核。

## 首板与费用边界

电源启动、负载、UPS切换、充电终止、温升及ML307/SIM/圆口实际装配尚待验收。没有完整ESP32/ML307/射频/音频联合仿真，也没有证明新PCB达到90%或99%成功率。

费用表按此版实际板和全部板载物料计算，分别列出5/100/1000片。外挂ESP32/音频、线束和装配预算独立可改。板厂指定叠层、阻抗、起订数量和模组装配工艺尚未取得整单报价，已单列工程预算预留。1000片ML307的5元另列为未确认条件，不作为已谈妥单价。

40轮旧样机连续性测试已经结束：33轮各自满1800秒、7轮中断；1次电脑监督器中断排除并补测。另在挂断阶段捕获ESP异常，不能把媒体通过数量当作完整流程无故障数量。见[最终实机回归记录](../../tests/at_recovery_batch_20261121.md)。这些测试使用现有手工接线设备，不是新PCB验收。
