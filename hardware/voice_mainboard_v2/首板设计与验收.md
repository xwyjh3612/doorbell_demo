# 语音对讲首板设计与验收

首板目标：圆口输入4.5～5.5V、标称5V，经稳压后ESP32和裸ML307R-DL正常启动，能刷机、入网、双向呼叫与通话；可选雷达接口保留。圆口及输入路径按3A设计，总负载与稳压功率仍需验证。设计、器件核对、布线和检查由本项目负责，用户提供实际购买器件的型号、照片、尺寸即可，不要求用户判断电路。

目前是未布线工程草图，不能发厂。没有首板实测或同板历史数据，不能给出90%/99%的数值成功率；仿真通过项占比也不能当作整机成功概率。以下是减少首版返工的设计和放行要求。

## 首版范围

- ESP32、麦克风、功放沿用现有模块与已调通引脚；主板直接贴ML307R-DL，SIM与天线在主板。ESP模块接线和安装方式须在装配资料中明确，主板本身不等于完整装配的设备。
- 基础上电验收使用当前UART AT，保留官方WebRTC协议和最新UDP包覆盖策略。当前实机40轮回归验证现有模块组合，不能替代新板电源、射频和装配验证。
- UPS按用户约定预留，芯片未确定时经J21独立稳压台架5V验下游，原始输入直通旁路已移除；4.5～5.5V宽压、备用电池、充电、UPS切换不算当前通过功能。USB通路保留互斥选装，首板AT通过后单独测USB。
- 基础通话测试先断开雷达电源，随后接回雷达测总峰值和通话；同一块板分阶段验收，接口保留。

## 降低同一块板的返修成本

下一轮布线前加入或确认以下位置。当前只有部分测试点和选择跳线，不能把全部预留说成已完成：

1. 已画入J19模组VBAT三针选择及J20外部3.8V输入：J19仅一个跳帽，1–2内置降压、2–3外部3.8V，无跳帽断开VBAT。新增13项引脚检查通过，连接器>=3A料号、接触压降与实物测试未完成。其余电源、ESP、功放、雷达支路隔离继续核对；不得并接两路电源。
2. 5V、VBAT、3.3V、1.8V、GND、PWRKEY、RESET、UART有可测位置；高电流路径不用细长飞线。
3. 反馈、滤波、开机和上下拉电阻采用便于返修的封装；关键候选电路留旁路/替换位置。预留不能补救所有封装错误或不合格RF布局。
4. 保留AT功能；USB可选装隔离，UPS未装时用J21稳压电源验证下游，再单独验完整宽压输入。不能接原始输入替代稳压电源。

## 打样前放行

以下必需项取得证据后，才输出生产Gerber、钻孔、BOM和贴片坐标：

1. 冻结首版装配范围、每个器件的厂家料号/参数/封装；功率器件、电容有效容量、电感饱和、供电路径和总峰值有计算与资料依据。
2. ML307、SIM、电源插座封装及信号方向独立核对；外壳和模块安装尺寸有实物/图纸依据。
3. 电源启动、负载突增、复位/开机/关机、掉电与倒灌检查完成。模型缺失项用候选电路台架证据补足，不能用假设模型宣称芯片稳定。
4. 原理图ERC、网表/焊盘、全部未连接、完整DRC通过；RF、USB、电源、地回流和热路径完成实际布线复核。
5. 文件区分已实现与仅预留功能；贴片资料含极性、方向、互斥选装、未贴料及装配说明，不让厂家猜测。

## 实板验收

首批先装配验证1块，同版其余板保留，基础上电正常后再装配其余板。分次装配是否可行及费用按实际厂家报价确认，目前未取得报价。

1. 不通电查短路、极性与焊接；支路断开，限流上电逐个测电源。限流过小会使4G启动失败，测试阶段和限流值要记录。
2. 先验ESP刷机、BOOT/RESET和TTL，再启动模组；测VBAT启动、入网和电流瞬态。万用表稳态读数不代替示波器瞬态测量。
3. 接音频完成通话，再接雷达，在4.5/5.0/5.5V输入分别测峰值、压降、温升和声音；核对充电与峰值叠加，实际电流符合输入路径和适配器能力。
4. 在新板上做冷/热启动、呼入/呼出/BOOT接听/挂断再拨与独立半小时通话；硬件复位、电源循环另测，不在健康通话中重启。
5. 1块基础通过后验其余样机，记录序列号、结果和返修；随后单独验USB，UPS及电池确定后验长期插电、切换与保护。

5块样机目标是全部具备首版功能。5块全部通过也不能统计推断量产成功率99%；量产良率需要更多同版、同工艺实物数据。
