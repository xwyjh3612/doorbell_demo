# 语音对讲 V2：ML307R-DL 贴主板、UPS与USB预留

这是可编辑的 KiCad 9 **原理图和未布线摆放草图**。供审查接口、电气连接和模块布局，尚不能交给贴片厂生产。旧 V1 留作历史参考。

用户已确定：ML307R-DL 裸模组直接焊主板；电源采用 UPS，芯片后续提供；ESP32 测电池电压并估算剩余电量；电源为2.5mm圆口；ESP32 TTL刷机只留4针；可选生命体征雷达接口保留；保留UART AT，并预留ESP32-S3 USB网络通路。

## 打开与预览

- `voice_mainboard_v2.kicad_pro`：工程入口。
- `voice_mainboard_v2.kicad_sch`：完整电气连接，标签同名即连接；未使用/保留脚有明确不连接标记。
- `voice_mainboard_v2.kicad_pcb`：实际焊盘和候选器件位置，**没有布线**。
- `exports/overview.svg`、`exports/review.html`：布局和供电采样仿真预览。
- `exports/validation.json`：KiCad 独立网表与焊盘对比、ERC、摆放DRC及未布线数量。
- `exports/power-simulation.json`、`exports/*.cir`：实际 ngspice RC 仿真结果和输入电路。
- [仿真审查报告](仿真审查报告.md)：扩展电路仿真、失败项、未覆盖功能和打样前阻塞项。
- [首板设计与验收](首板设计与验收.md)：首版功能、降低返工的设计要求、打样前放行及实板验收次序。
- `exports/function-simulation/index.html`：功能覆盖表、波形和可复现的SPICE输入。

暂定板框100×75mm，4个通用M3孔。与曾讨论的115×90×55mm外壳**尚未核对内尺寸/螺柱/接口开孔**；ESP32、麦克风和功放仍通过线束接现有模块，不假装已知开发板排针间距。预留23×28mm UPS区域仅为布局预算，实际芯片、电感、散热及电池接口确定后可能调整板框。

## 供电路径

```text
5V适配器 -> J1 圆口 -> J2 -> UPS输入
                         UPS稳定5V输出 -> J3 -> SYS_5V
SYS_5V -> ESP32 5V（JP3选择） / MAX98357 / 可选雷达
SYS_5V -> 独立降压候选TPS563201 -> BUCK_3V8 -> J19选择 -> ML307R-DL
受保护单节电池端 -> J4采样线 -> 可关闭分压 -> ESP32 ADC
```

ML307R-DL裸模组不能接5V。VBAT额定范围3.4–4.5V，典型3.8V，供电须应对2A瞬态。TPS563201是**给模组降压的候选器件，不是你尚未提供的UPS芯片**；其最低输入4.5V，要求UPS输出在负载下稳定。39.2k/10k反馈用0.768V参考计算约3.779V，实际精度、纹波、启动、2A负载和散热尚未测试。

预留2×220µF、2×22µF等供电电容。484µF按2A、允许下降0.4V计算，仅约97µs储能；不能用这些电容掩盖UPS切换时毫秒级断电。后续需测5V与模组端VBAT的切换波形。电池不能只看容量，还要核对保护板和电芯放电倍率；例如5V端10W负载、90%效率、3.7V电池需约3A电池电流。

当前 J4 **只接电压采样线，不是电池大电流接口**。电池充放电、保护、温度检测、反接保护、输入限流及电源路径在UPS芯片确定后设计，不预置一个猜测的PMIC封装。J5的CHRG/DONE/PG仅预留3.3V兼容开漏接口，上拉默认不贴，须核对具体芯片。

### 模组供电隔离和返修接口

J19是三针选择位：**仅放一个跳帽**，1–2用板载降压，2–3用J20外部稳压3.8V；拔掉跳帽隔离模组VBAT。J20第1针为外部3.8V、第2针GND，**不能接5V**，电源须保证模组端3.4–4.5V及至少2A瞬态能力。跳帽、排针和供电连接器须冻结>=3A的具体料号，接触压降计入供电预算；草图中的通用封装不是额定电流证明。

此接口用于先单独测试降压，再接模组，也允许隔离板载降压、接经验证的电源继续诊断同一块样板。不能同时放两个跳帽，否则两路电源相连。反馈R2与C6/C7在BUCK_3V8侧，模组大电容留在MODEM_3V8侧；正常连接时总电容仍约494µF，**这没有解决当前降压器稳定性未验证的问题**。大电流走线、接触电阻、切换和倒灌尚未实测。

## 2.5mm圆口

按常见5.5mm外径、2.5mm内径，中心正极，**输入5V**设计。J1目前使用库中对应尺寸的候选封装，不能直接购买外观相似的DC-025、DC-005插座并假设孔位相同；最终按实际低价插座尺寸图替换。2.5mm内径是本轮的合理解释，待实物型号核对。

JP1是临时台架旁路：无UPS时可连接外部5V与SYS_5V；安装UPS时移除。它不是自动电源切换电路。

## ESP32 4针TTL刷机口 J18

| 针序 | 主板丝印含义 | USB-TTL连接 |
| --- | --- | --- |
| 1 | GND | GND，共地 |
| 2 | TX43 | TTL RX |
| 3 | RX44 | TTL TX |
| 4 | 5V | 可选板端供电；UART信号仍为3.3V |

JP3是单个3针电源选择：1–2接系统5V，2–3接TTL的5V，**不可同时短接两侧**。正常调试/刷机优先主电源供电，只接GND/TX/RX。USB-TTL的5V能力不作为4G和功放的整机供电来源；若选择TTL供电，仅给ESP32支路，不给SYS_5V。

四针没有DTR/RTS，因此采用手动下载：按住SW1 BOOT，按下并松开SW2 RESET，随后松开BOOT，用esptool/ESP-IDF刷机。GPIO0兼作已有呼叫按键；重启时按住它会进入下载模式。SW2连接现有开发板EN。当前固件UART0 GPIO43/44和协议未修改。

ML307另有1.8V调试点和USB维修接口，**不是ESP32刷机口**。模组USB_VBUS只做插入检测，不能替代VBAT供电。

## 电池电压与粗略电量

暂按普通单节4.2V满充锂电池设计，不适用于未经调整的磷酸铁锂或4.35V电池。

- GPIO2 / ADC1_CH1：电池电压输入；GPIO9：采样开关。两者为硬件建议，需核对实际开发板可用引脚。
- BSS84高侧开关 + 2N7002驱动，在ESP32无电时默认关闭，避免电池持续通过ADC脚倒灌。其器件漏电和实际上电行为仍需硬件验证。
- 上150kΩ、下100kΩ，节点100nF。电池4.2V时节点约1.68V；`电池电压 = 已校准ADC电压 × 2.5`。
- 分压戴维宁电阻60kΩ，时间常数6ms；ngspice达到0.1%稳态约41.5ms，建议开启后等待60ms再多次取样。ADC使用IDF校准和合适衰减档，例如12dB，并检查实际板上测得的范围/误差。
- 1%分压电阻单独引入约±1.2%还原误差，另有ADC误差和电芯/负载差异；用万用表至少校准几个电压点。
- 后续固件建议每30–60秒采样，短时打开分压，取多次中值，再做缓慢滤波。采样打开时分压约16.8µA，门极上拉支路约42µA；关闭时以器件实际漏电为准。
- 电量采用选定电池的电压表做分段插值，并标为“估算”。**不使用3.0–4.2V线性比例直接冒充真实电量**。通话负载压降和充电抬升会影响显示，需分别处理，低电保护依据经实测的电压阈值。
- 电压估算不能可靠给出剩余待机小时数；选定电池后测空闲/通话功耗及实际放电曲线，再估计。

GPIO10通过开漏MOS检测UPS之前的外部输入，低表示外部5V存在，高表示掉电。R19改为10k 1%、R20为100k 1%，Q5指定Diodes 2N7002K-7，避免旧100k/100k给门极的电压落在最高阈值附近。该简单电路用于检测插拔，**不是准确欠压比较器**；缓慢降压的触发点取决于MOS阈值，后续有PGOOD芯片可替换。掉电先由UPS维持整机，ESP32去抖后发掉线原因；电量耗尽前的关机和联网失败重试策略需等UPS与电池选定后实现。

## ML307接口

ESP32 TX17 -> 1.8V转换 -> ML307 RX17；ESP32 RX18 <- 1.8V转换 <- ML307 TX18；ESP32 GPIO4 -> DTR19。选用固定方向SN74AXC1T45候选，支持当前921600波特率，A侧3.3V/B侧1.8V；电源由模组VDD_EXT提供，电压/方向已对厂家引脚表核对。

ML307R-DL本体17.7×15.8×2.2mm、109焊盘，厂家手册p19引脚图、p56推荐焊盘。自定义封装按PCB顶视转录，48外围+61内部，保留脚全部悬空，GND只连接厂家表列出的脚。**仍需厂家CAD/实物1:1叠图和钢网开口确认**，不能用“109个焊盘存在”替代封装签核。

SIM卡座、串联22Ω、可选33pF、低电容ESD、U.FL及天线π匹配位已画入。SIM卡座/ESD/电感/电解电容均是候选型号或封装，最终采购前需要冻结。RF须按实际板材叠层设计50Ω，USB维修线须按90Ω差分布线；未进行射频或实际模组行为仿真。

PWRKEY用开漏MOS，手动启动接口保留；GPIO11控制和GPIO21复位仅预留，当前业务固件不会自动驱动。手动开机拉低2–3.5秒，需在VBAT稳定至少500ms后进行；正常关机需按厂家规定3.5–4秒。自动开机4.7k位置默认不贴，不能擅自让设备失去关机能力。

麦克风GPIO14/13/12、功放GPIO15/16/7、雷达TX->GPIO6及预留RX<-GPIO8沿用已调通方案。雷达电源JP2可拔掉；固件仍使用现有可选编译配置。板图生成不接触实机固件；当前AT恢复修复与呼叫测试见[实机回归记录](../../tests/at_recovery_batch_20261121.md)，官方协议及主动丢旧包策略保持原样。

## USB网络与维修口的选择

裸ML307R-DL的59脚D+、60脚D−、61脚VBUS检测已在主板草图中连接到两组选装0Ω电阻。ESP32-S3使用GPIO20 D+、GPIO19 D−，通过J13新增的28/29/30针预留D−/D+/GND；原J13的1–27针不变。J12保留模组USB维修口。

| 用途 | 贴装0Ω电阻 | 不贴电阻 | 数据与VBUS来源 |
| --- | --- | --- | --- |
| 默认：电脑维修模组 | R26、R27、R30 | R28、R29、R31 | J12电脑端D+/D−和VBUS |
| 产品：ESP32 USB Host网络 | R28、R29、R31 | R26、R27、R30 | ESP32 GPIO20/19与SYS_5V检测电压 |

**两组不可同时贴装。** 该选装隔开电脑维修口和ESP32主机，避免两个USB主机同时驱动模组或两路5V相连。模组61脚只做VBUS检测，范围3–5.25V，不能替代3.8V VBAT供电；SYS_5V峰值仍需实测满足上限。ESP32作为Host时，其原生USB口不能再接电脑；独立四针TTL调试保留。

选装Host组后，UART17/18及DTR4仍连接，可编译选择当前AT方案或后续RNDIS/ECM方案。选择维修组时，USB没有连到ESP32，软件开关不能替代补焊Host组。当前量产草图预留这项能力，正式固件尚未加入统一的传输选择或运行中热切换；独立[USB实验项目](../../examples/ml307_usb_net_demo/README.md)已分别构建RNDIS/ECM，未做实物USB通话验证。

J13目前是接口位置占位，最终须换成适合USB全速信号的短连接/板对板接口或将ESP32直接布在主板。USB差分90Ω叠层、低电容ESD、回流路径、分支长度及连接器尚未设计；长杜邦线不作为验收方案。现有Tiny CORE小板没有已确认的USB引出点，本次预留用于后续裸模组主板，不要求现在购买或改焊小板。

## 仿真和生产边界

2026-11-21扩展审查已执行107项独立接口引脚核对（其中19项USB接口/选装电阻、13项模组供电隔离接口）、4项当前固件引脚核对和67组完整SPICE瞬态（27组采样开关/分压参数、3组漏电与掉电情景、27组外部电源检测、2组按钮RC、4组模组控制、3组供电阻抗、1组电容储能）。MOS模型为显式标注的通用参数模型，不是厂家器件完整模型。另尝试4组未经修改的TI官方降压模型，均因ngspice瞬态步长错误提前中止，报告为未验证。

**本版没有通过整机验收。** 外部输入检测已改10k/100k并指定Q5料号，27组通用模型通过，实测未完成。TPS563201约494µF输出电容超出数据表20–68µF推荐范围，稳定性/启动需单独确认；ML307电源循环要求VBAT在1.8V以下至少100ms，当前未设计专用残压放电路径，自动开机控制尚未实现。UPS芯片及电池未选定，不能验证充放电与切换。详见扩展报告及首板验收要求。

实际执行了ngspice分压RC阶跃仿真，以及理想3.8V源、等效供电电阻、484µF/50mΩ电容、0.3->2A负载的RC瞬态仿真。50/150/300mΩ供电路径对应最低约3.70/3.50/3.20V，说明供电阻抗必须控制；**不是对候选降压芯片或未选UPS的完整仿真**。没有模拟开关反馈、线缆电感、射频、实际语音芯片，也没有证明现有掉话根因是供电。

进入打样前还需：取得UPS芯片资料与电池规格；确认圆口/SIM/ESD/电感/电容采购型号和实物尺寸；完成模组封装签核、叠层与RF/USB/大电流布线、接地和EMC设计；DRC含所有未连接项清零；核对外壳结构；做负载、掉电切换、低电关机、充电温升和持续通话实测。当前不导出可被误下单的Gerber。

参考资料：[ML307R硬件手册](https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1189/M307R_Hardware_Datasheet.pdf)、[TPS563201](https://www.ti.com/lit/ds/symlink/tps563201.pdf)、[SN74AXC1T45](https://www.ti.com/lit/ds/symlink/sn74axc1t45.pdf)。价格需要按最终BOM询价，未把候选进口连接器/芯片当作整机80元目标下的最终采购。

## 重生成

在项目根目录用KiCad自带Python依次运行`generate_design.py`、`generate_schematic.py`；用kicad-cli输出KiCad XML网表、ERC JSON和PCB DRC JSON到exports，运行`verify_design.py`；系统Python运行`simulate_power.py`与`simulate_functions.py`，最后用KiCad Python运行`generate_review_assets.py`。也可运行`regenerate.ps1`。验证器独立对比KiCad网表和PCB焊盘，保留未布线数量；ERC通过不等于可生产。扩展仿真需要KiCad配套ngspice；绘图可安装matplotlib 3.10.7到项目`build/cad-tools/sim-python`。TI模型自动从官方URL下载到被忽略的build目录，原文件不修改、不放进Git；SHA256及提前中止原因写入JSON报告。单独运行仿真不接触串口、当前固件或实机通话。

`regenerate.ps1`最后调用`render_exports.mjs`同步布局和原理图PNG，使用`build/svg-render`内的`@resvg/resvg-js`2.6.2及系统字体。依赖可用`npm install --prefix build/svg-render @resvg/resvg-js@2.6.2`安装。SVG保留完整可缩放原图，PNG仅供快速预览。
