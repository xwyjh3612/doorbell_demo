# 语音对讲主板 V4

本版按用户选择采用ESP32-S3-WROOM-1-N8R8＋ML307C-DL，100×75mm双层板、单面SMT。最新目标为1000台时主板含PCB、板上零件及加工约50元/台，不含外设；继续用低价圆口接5V/2A适配器。具体计价范围与后续选料上限见[量产1000台50元约束](cost/量产1000台50元约束.md)。V3历史工程保留；本目录为尚未生产放行的工程候选，最新实际检查见`exports/validation.json`。

## 接口及功能

| 部分 | 设计 |
|---|---|
| ESP32 | 集成N8R8模组，保留当前通话GPIO；8MB Flash/8MB PSRAM，120MHz PSRAM配置与采购版本待验证 |
| 4G | C-DL裸模组；UART17/18、DTR4；PWRKEY/RESET控制，USB维修/ESP Host互斥0Ω选装 |
| 主供电 | 中心正极5.5/2.5mm圆口；标称5V/2A，输入4.5～5.5V边界尚未负载验收 |
| UPS | 板上充电、双源切换及硬件欠压控制；外接受保护1S电池包和10k B3950 NTC，电池包及接点电流能力须实测 |
| 电池采样 | ESP GPIO2分压采样，GPIO9控制；估计剩余电量，无独立燃料计 |
| 音频 | MAX98357A单声道I2S功放直接贴板；INMP441仍采用可放在外壳声孔附近的小模块，模块成本单独计入总成 |
| 呼叫 | BOOT0键及外部常开按钮；ESP复位键 |
| TTL | J18针序GND、ESP TX43、ESP RX44、5V；3.3V逻辑，主电源供电时TTL 5V不接 |
| 可选雷达 | J16针序5V、GND、ESP RX GPIO6、ESP TX GPIO8；默认R58不贴，可选24G/60G模块；固件按原配置裁剪 |

USB选装：电脑维修贴R26/R27/R30，ESP Host贴R28/R29/R31，两组互斥。USB检测VBUS不能给裸模组VBAT供电。Host联网驱动尚未加入当前固件；硬件预留不等于已验证USB通话。

## 供电结构

外电经保护和3.792V降压接入双源切换器VIN1；受保护电池经硬件欠压开关接VIN2。POWER_BUS给4G供电，并分支生成ESP 3.3V和音频/可选雷达4.992V。充电默认约100mA。控制电阻网络进行了实际ngspice行为模型及容差计算，完整稳压闭环、启动、切换、热和整机功能尚未通过仿真/实物验收。

## 成本与采购

ML307C-DL=10元、N8R8=12元为用户指定采购目标。其余器件混用历史页面参考与未询价预算，不能视为已报价BOM。商城C-DL价按用户提供的5只19元、100只16.84元、1000只16.45元另列。目标是1000台时量产完整主板约50元；当前板上物料预算57.89元尚未达到，加工及损耗仍需计入。外接麦克风模块按用户最新“不含外设”的范围单独列示。详见`cost/预算与降本.md`。

新核查的[非UPS低价替代料](cost/低价替代料核查.md)包含SIM座、四路SIM保护、ESP降压和条件4G降压的具体型号、公开阶梯价和资料复核。前三项条件材料节省5.72元/台；含条件4G降压的材料预算约49.78元仍不含加工。用户约5元UPS板待到货再定，本轮未改变当前PCB/BOM，不能把候选的价格和原板验收状态混用。

按用户最新指定的5V供电与UPS材料共5元，[1000台重算](cost/5元UPS量产重算.md)：采用前三项低价候选且保留原4G降压时，材料44.79元、含PCB/加工/测试预算53.29元；条件低价4G降压方案材料42.40元、完整主板预算50.90元。5元已包含圆口及输入保护时，后一情景为49.61元。以上仍是独立成本方案，UPS型号、输入边界、候选设计及工厂报价尚未确定；原PCB/BOM和验收记录保持原基线。

## 资料来源与复核

C-DL专用符号/109焊盘来自**嘉立创EDA/EasyEDA官方库 / JLCEDA/EasyEDA Official Library**，主页：[嘉立创EDA](https://lceda.cn/)、[EasyEDA](https://easyeda.com)。完整来源、UUID、下载SHA256、引脚、焊盘坐标与归属说明保存于`sources/ml307c-dl-library.json`；库数据不是厂家完整硬件手册。C-DL具体固件AT命令、USB枚举、UART电平、PWRKEY/RESET时序与钢网仍需确认。

本轮不改动ESP官方WebRTC协议、实时UDP主动丢旧包逻辑或正在使用的固件。不在旧R模块上声称验证了新C-DL主板。打样前必须通过PCB设计检查、DFM/配单、器件封装审查，以及电源和新模块实机验收。
