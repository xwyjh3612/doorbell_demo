# 1000台主板约50元的设计约束

用户最新确认：1000台量产；约50元/台包括主板PCB、板上默认器件、贴片/插件加工。外接5V/2A适配器采用低价中心正极5.5/2.5mm圆口，不强制改USB接口。设计输入范围保持4.5～5.5V。5V供电不能直接接ML307C-DL的3.4～4.5V VBAT；4G电源转换仍需保留。

外设不计入本目标：适配器、电池包/NTC、外壳、喇叭、雷达、线束及放置在声孔附近的外接INMP441麦克风模块。板上的UPS充电、切换、电量采样、I2S功放仍计入主板成本。若麦克风改成板载裸器件，必须重新计入主板BOM。

## 实施顺序

1. 核实C-DL 10元和N8R8 12元的可采购版本、税运、批次和客供SMT政策。商城C-DL 1000只16.45元档比10元目标高6.45元，必须另行解决采购差额。
2. 保持双层、单面贴片、普通0.3mm钻孔。当前100×75mm是布线基线；只有布局和地参考允许时再缩板，先按同尺寸取得真实PCB/SMT报价。
3. 优先替换高价SIM座/ESD，用有厂家手册和现货的兼容料。当前合计5.92元；低价替代必须核对引脚、封装、电容、钳位能力，不能直接按价格换。
4. UPS和电源是主要降本对象。重新核查集成电源方案、低价等效稳压/切换器件与实测电流。保持备用供电和关机上报要求，不能通过默默去掉UPS达到目标。
5. 保留3W级单声道I2S功放。低价替代须核对输入格式、增益、关断行为、功率和扬声器负载，避免破坏已调通的固件。
6. 软件协议和主动丢旧包逻辑保持当前版本。新板电源控制GPIO、C-DL固件及USB模式另做适配和实机验收。
