## 供电结构

圆口 5.5/2.5mm，中心正极，使用 5V/2A 适配器。接口设计输入范围 4.5～5.5V；上限不是过压保护能力。外电正常时经反接保护与 TPS2117 直接供系统，电池经 ETA1096 升至约 5V 备用。外电通路存在压降，系统电压不会始终等于 5.000V。

TP4056-MS 以约 300mA 充电，Q7/GPIO38 可暂停充电；电池保护采用 XB7608AJL，ME2807A30 在电池约 3V 时关闭升压。保持升压待命，避免等 ESP32 软件启动才切换。ESP32 与 ML307 分别降压供电，功放与可选雷达接系统电源。

J23 三针是 **CELL+ / CELL- / NTC**，连接单节 4.2V 锂离子电池及 10kΩ/B3950 热敏电阻。**CELL- 是电池保护芯片前的裸电芯负极，不能与主板 GND 短接。** NTC 相对 CELL-，R65/R66 配合温度窗口；具体电池、NTC 阻值/温度及充电参数须按采购型号确认。未接 NTC 时当前网络会禁止充电，不能当作两线电池板随便接。

## ESP32 知道什么

| 功能 | GPIO | 电路和含义 |
|---|---:|---|
| 实际选择的电源 | 47 | TPS2117 ST，低表示没有选择外电；正常运行且电池支路有效时为电池供电 |
| 外电是否接入 | 10 | Q5 检测，低表示外电已接入，不能判断适配器电流能力 |
| 电池电压 | 2 | ADC1_CH1，150k/100k 分压，电池电压约为校准 ADC 电压的 2.5 倍 |
| 电量采样开关 | 9 | 使能分压，每次等待 40ms 后取样，随后关闭 |
| 暂停充电 | 38 | 高经 Q7 拉低 TP4056 CE；呼叫/通话/OTA 期间暂停 |
| 正在充电 | 48 | TP4056 CHRG，低有效，3.3V 上拉 |
| 已充满 | 1 | TP4056 STDBY，低有效，3.3V 上拉 |

电量是电压曲线估算，同时报告毫伏值；不是库仑计，充电、通话负载、温度、电池型号会影响准确度。ADC 无有效校准或读数越界时报告未知，不显示虚假的 0%。当前接入状态假定按设计安装电池，不支持只靠 TP4056 BAT 电压可靠识别电池热插拔。

ST 在芯片关断、欠压、过温时也可能拉低；它表示芯片选择状态，不能测量实际电流或保证输出正常。故障诊断仍需测系统电压。新主板须实测正常外电、断外电、恢复外电、低电量和充电中的读数。

## 固件、服务器与 App

`CONFIG_VOICE_POWER_MONITOR_ENABLE` 默认关闭。已有开发板继续用 `voice` / `voice-radar` / `voice-radar60`。新主板启用 `mainboard-v6` 或 `mainboard-v6-radar60`：

```powershell
# 先启用已有 ESP-IDF 环境
tools/build-firmware.ps1 -Variant mainboard-v6-radar60
```

`power_status` 串口命令显示供电来源、电压、估算百分比、充电状态及采样时间。每秒本地采样，通话期间保持采样但禁止这项 MQTT 上报；待机约每 30 秒发布最新快照到原 base topic 下的 `设备ID/power`，不积压旧快照。原官方信令与 UDP 主动丢旧包实现不变。

服务器独立接收 `/power` 并附在 `/telemetry` 的 WebSocket/HTTP 快照中。App 显示“外部供电 / 电池供电、约百分比、V、充电中”，超过 60 秒标记过期；通话期间缓存标明挂断后刷新。新 APK 位于项目 `outputs/android/voice-intercom-demo.apk`，本轮仅构建，未发布或在现有硬件上刷写。

## 生产前仍需完成

1. 选择实际电池与 NTC，核对容量、充放电倍率和温度窗口。
2. 实测 5V/2A 峰值、低电池升压、断电接管压降、恢复外电及温升。ETA1096 的 30k 限流最小值未给保证；U17 的温升需验证。
3. TPS2117 PR1 内部参考 ±8%，当前 100k/33.2k 的切换门限理论约 3.687～4.340V。最坏门限与模组欠压之间的裕量需实测，不能把标称 4.012V 当精密阈值。
4. 核对保护芯片 CPC5、TP4056 和 ETA1096 焊盘/钢网，以及保留的 ESP 模块散热孔和功放钢网开口工艺；替换库存不足的电感。电容需核对直流偏压后的有效容量。
5. C-DL 的硬件手册、AT/USB 固件兼容、SIM/RF/USB、新板通话及量产工艺验收。

ERC、DRC 和分压计算通过不会证明整板功能或 99% 成功率。电源铺铜及 0.6/0.3mm 普通过孔是布局实现，电流额定值仍需热与压降验收；当前不提供生产放行标记。
