## 供电与接口

```text
稳压外电约5.2V ─┬── TPS2117 VIN1 ─────────┐
                └── TP4056 ─ 受保护1S电池  │
                              │            ├── SYS5V：ESP32、4G、功放
                              └──TPS61230A─┘              └──JP2──可选雷达
                                     VIN2

比较器+基准：外电检测和硬件优先切换
电池欠压监控：独立关闭升压；外电仍可供系统
电池/外电分压：预留ADC接口，具体ESP32 GPIO待分配
```

| 接口 | 本底板引脚次序 | 接法或限制 |
| --- | --- | --- |
| J1 外电 | 1 VIN_EXT，2 GND | 约5.2V稳压输入，绝不超过5.5V；当前适配器料号未固定，输入电压/电流须按负载验证 |
| J2 电池 | 1 VBAT，2 GND | 受保护单节4.2V体系锂电池包；暂按≥5A持续放电选型；不直接接未保护裸电芯 |
| J3 4G电源 | 1 SYS5V，2 GND | 仅接自研板经确认支持5V的板级入口，不能直接给裸ML307的电池入口5V |
| J4 电池NTC | 1 NTC，2 GND | 电池上的10kΩ NTC；B值未冻结；断开NTC按设计暂停充电 |
| J6 4G UART | 1 GND，2 IO17，3 IO18，4 IO4 | ESP TX17→4G RX；ESP RX18←4G TX；IO4→DTR；核对原板逻辑电平 |
| J7 麦克风 | 1 3.3V，2 GND，3 IO14，4 IO13，5 IO12 | BCLK14、WS13、数据12，L/R选择保持当前已验证模块接法 |
| J8 功放 | 1 SYS5V，2 GND，3 IO15，4 IO16，5 IO7 | BCLK15、WS16、数据7；增益/关断脚沿用原模块接法；喇叭接功放两路差分输出 |
| J9 可选雷达 | 1 RADAR5V，2 GND，3 IO6，4 IO8 | 模块TX→第3脚→ESP RX6；模块RX←第4脚←预留ESP TX8；GPIO8当前固件不驱动 |
| JP2 雷达电源 | 1 SYS5V，2 RADAR5V | 基础款不装雷达且不短接；安装模块时可短接；这是人工跳线，未实现软件电源关断 |
| J10 呼叫按钮 | 1 BTN，2 GND | 常开自复位按钮；10k上拉和100n滤波；JP1选择GPIO0或GPIO9 |
| JP1 按钮IO选择 | 1 IO0，2 BTN，3 IO9 | 1–2选择GPIO0，2–3选择GPIO9。旧GPIO0固件使用下拉/基线变化逻辑，新电路需适配，不能宣称插上即呼叫 |
| TP1 / TP2 | IO43 / IO44 | ESP UART0 TX / RX测试焊盘，不带额外供电 |

## 电气设计中已算出的值与待验证项

- TPOWER TP4056的2.7kΩ PROG电阻按1100/2700得到约0.407A充电，仍须计入实际芯片偏差与电芯允许充电电流。
- 331k/100k反馈分压给出TPS61230A PWM典型输出5.15045V。基准上下限及电阻误差会改变输出；不能只按典型值保证R60的4.9～5.5V、≤100mV纹波。
- 电池欠压器件是TLV803EA30DBZR，下降阈值标称**3.08V**，不是3.00V；释放延时200ms。欠压后的电池电压回弹可能触发重复启动，要实测并评估关断滞回/锁定策略。
- LM393+TL431B外电检测使用105k/100k分压、5.6M反馈。按2.495V基准、输出低0.2V/高4.9V，外电上升约5.158V、下降约5.070V；这是典型假设，需计入LM393（不是B版）的偏置/失调、TL431误差、供电和温度。适配器的实物最低电压必须高于最坏恢复阈值，尚未确认。
- 9.1k上臂、3.3k串10k NTC下臂在25℃名义分压为0.594VCC；名义45%/80%阈值对应NTC约4.145k/33.1k。仅在B=3950K假设下对应约46℃/0℃，实际窗口须按固定NTC规格和阈值偏差重新核算。
- SYS5V后470µF并不等于切换完全无压降；还要核算总模块电容、ESR、启动浪涌和负载突变。升压局部2×22µF需选择有足够有效容量的实物电容。
- 主板暂未实现受控功放/雷达断电，也没有冻结外电输入保护与USB防倒灌方案。首次验证用有限流的台式电源；开发板USB供电和底板5V不能在隔离未核对时同时连接。
- 电池ADC、外电检测、掉电上报后的省电逻辑尚未加入固件。1000mAh容量是预算输入，不能承诺带着4G持续在线可待机几小时。

## 继续到可打样文件

先取得实物尺寸、固定电池与适配器规格、确认模块输入，再完成电源大电流环路、铜皮/散热、保护及其余布线；检查原厂焊盘、钢网及最终阻容料号。完成ERC/完整DRC、装配与机械复核之后才导出Gerber、钻孔和贴片坐标。

首板需先做电源空载/2A负载/低电池/切换/充满长期插电测量，再接原有通话硬件验证。原固件经过人工测试，不代表新电源PCB已经通过。

## 重建与检查

用KiCad 9 Python运行generate_design.py，普通Python运行generate_schematic.py。使用kicad-cli导出原理图kicadxml网表并运行ERC和PCB DRC后，用KiCad Python运行verify_design.py。检查脚本对比网表、PCB焊盘和设计表的171个已命名引脚连接，明确保留未布线状态；具体计数以validation.json为准。

原厂资料与选型依据见[首版PCB与备用电源选型](../../首版PCB与备用电源选型.md)。
