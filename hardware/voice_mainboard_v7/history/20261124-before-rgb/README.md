## 本次完成的局部修改

- 功放100nF C62与U14电源焊盘中心直线距离，从约5.63mm降到约1.95mm。
- 功放10µF C61与对应电源焊盘距离约4.21mm，较原位置缩短；它不是当前最佳完整布局，整板重排时还要继续改善。
- 充电输入C67与U16电源焊盘距离，从约8.05mm降到约2.62mm。
- 充电电池侧C68与U16 BAT焊盘距离，从约5.34mm降到约3.75mm。
- 重接局部电源与地，清理因电容移位遗留的无效支路。供电路径连通不代表动态、热与最大电流已经验证。
- 保留前一候选对主输入细线的修复。

上述数字是焊盘中心直线距离，不是环路长度、等效电感或实测噪声结果。[当前检查记录](exports/local-layout-validation.json)绑定当前PCB哈希；不使用旧版检查为新版背书。

## 充电与无电池使用状态

2026-11-24核查：当前未实现80%停充/70%再充；现有电源监测仅在呼叫、通话、OTA暂停充电，功能默认关闭。TP4056-MS按约4.2V、名义300mA充电。已有GPIO38→Q7→CE可供后续实现电量迟滞控制，无需另加控制芯片。

外电通路独立于电池，设计上支持不装电池、仅插5V电源。电池及NTC均不接时，现温度分压约0.89×VCC，按芯片规格暂停充电；整板外电启动与负载能力仍待实板测试。ADC读到电压不能单独证明已安装电池，固件不得将无电芯的输出电容电压当作有效SOC。

本次已运行当前阻值的ngspice被动/理想控制子电路，并核对实际PCB引脚网络；未进行电芯化学充放电、充电IC/升降压完整厂家模型或整板电气仿真。现假设10k/B3950 NTC的名义温度窗口约−7～38.5℃，−5℃仍允许充电，必须按选定电芯修正。TEMP短到地会禁用温度监测，不能视为自动停充。详见[充放电与无电池核查记录](exports/charge-supply-audit/充放电核查.md)。
