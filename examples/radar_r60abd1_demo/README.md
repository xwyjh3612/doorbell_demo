# R60ABD1 60GHz 呼吸睡眠雷达 demo

用户新模块的包装为 MicRadar R60ABD1，板贴纸为 R60ABD1.1 / V0220。本演示由电脑解析现有语音＋可选雷达固件的 UART 历史快照，实时显示目标活动、有人/无人、呼吸、心率、距离、体动、床位及原始报文。仅添加电脑端程序，无需刷写 ESP32。ESP32 的 MQTT、官方 WebRTC/peer 协议及低延迟 UDP 策略保持原样。

## 接线与运行

| 雷达 | ESP32-S3 / 电源 |
| --- | --- |
| TX | GPIO6，ESP32 UART2 接收 |
| RX | GPIO8，当前固件不驱动此引脚 |
| 5V | 稳定 5V 供电 |
| GND | ESP32 GND，共地 |

UART 为 115200、8N1、3.3V TTL。厂家用户手册建议 4.9–5.5V，输入电流能力至少 200mA，电源纹波不超过 100mV。不能把 5V 电源接到 ESP32 GPIO。先让天线面朝胸口，在约 0.4–1.5m 静坐观察，避免金属遮挡；此距离来自当前厂家 H 版资料，具体板子适用范围还需实际验证。

项目根目录运行：

```powershell
.\examples\radar_r60abd1_demo\start.ps1
```

打开 [http://127.0.0.1:18890](http://127.0.0.1:18890)。脚本复用/启动 [radar_monitor](../radar_monitor/README.md)，仅该采集进程占用 COM13。它每 5 秒向 ESP32 控制台读取 `radar history`，不向雷达下发配置。页面每秒刷新，不能据此推断雷达的精确发送时刻。

前台运行（须先启动原采集服务）：

```powershell
F:\Espressif\python_env\idf5.4_py3.11_env\Scripts\python.exe examples/radar_r60abd1_demo/demo.py
```

停止本页面服务：

```powershell
.\examples\radar_r60abd1_demo\stop.ps1
```

关闭页面或停止 demo 不会停止串口采集。电脑重启后需重新启动脚本。运行日志/服务元数据保存在 Git 忽略的 `build/r60abd1-demo-*` 与 `build/r60abd1-demo-service.json`。导出仅包含雷达帧及本次数据，不包含语音/MQTT/SDP 控制台日志。地址只供本机访问。

## 解析与有效性

帧头 `53 59`，大端 2 字节负载长度，累加低 8 位校验，帧尾 `54 43`。重新校验后按采集服务 epoch/字节偏移去重。本次 demo 启动前的帧不导入；采集服务重启、引脚变化、设备计数重置或雷达初始化后清除旧测值。

| 控制字 / 命令字 | 含义 | 处理 |
| --- | --- | --- |
| `80 01` | 存在 | 0 无人，1 有人；不凭距离/心率推断 |
| `80 02` | 活动 | 0 无，1 静止，2 活跃 |
| `80 03` | 体动 | 0–100 |
| `80 04` | 距离 | 2 字节大端，cm；0 为尚无有效距离 |
| `80 05` | 方位 | 当前实测为 4 字节；保留原始值，不套用新版 6 字节 XYZ |
| `81 01` / `81 02` | 呼吸状态 / 频率 | 频率 1–35 次/分；0 为尚无有效测量 |
| `85 02` | 心率 | 按厂家手册 60–120 次/分；0 为尚无有效测量；超范围保留原值但不列为有效 |
| `81 05` / `85 05` | 波形 | 收到才显示，5 个点减去中轴 128；不合成假波形 |
| `07 07` | 探测范围 | 0 范围外，1 范围内 |
| `84 01` | 床位 | 0 离床，1 入床，2 无/实时模式 |
| `84 02` | 睡眠 | 只显示原始值；新版 V3.6 为 0 深睡、1 浅睡、2 清醒、3 无，旧板不直接套用 |
| `84 03–06` / `84 0C` | 时长、评分、综合信息 | 时长大端分钟，评分 0–100；综合字段保留原始值 |

存在/活动/床位等为变化上报，保留最近状态并显示采集时间；串口失联时标记过期。呼吸、心率等周期数值 12 秒未更新时标记过期。厂家说明呼吸/心率约 3 秒、睡眠约 10 分钟上报，睡眠不会立刻得出结果。当前 512 字节/5 秒采集适合状态演示，高速开启波形后可能覆盖未读取历史，不能当作无损波形采集器。

短时收到合法生命体征报文仅证明数据通路与功能输出，检测准确率、睡眠分类及长期稳定性需后续对照测试。实测见 [TEST_RESULTS.md](TEST_RESULTS.md)。

协议依据：[厂家 R60ABD1 文档目录](https://www.micradar.cn/technology-21-60-69-1.html)、[R60ABD1 用户手册 V3.6](https://www.micradar.cn/uploads/soft/20260923/1790165048.pdf)。该手册历史记录说明早期版本曾修改方位长度与睡眠枚举，因此不把未验证的旧板坐标解成新版 XYZ。
