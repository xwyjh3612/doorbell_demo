接线：雷达 TX → ESP32 GPIO6，雷达 RX → GPIO8，5V 供电并共地。当前为被动接收。页面约每秒刷新，ESP32 历史快照约每 5 秒读取一次；时间为电脑发现报文的时间。呼吸、心率原始值为 0 时显示“尚无有效测量”。

摆放建议：天线面朝向胸口，先在约 0.4–1.5 米距离静坐观察，避开金属遮挡。以上读数用于功能演示，准确性还需对照测试。
