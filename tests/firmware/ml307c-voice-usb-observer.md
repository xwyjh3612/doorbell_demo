# ML307C语音对讲USB故障观察调试版

用途：在原UART AT语音通话固件中观察USB设备枚举、断开与重连，确认异常时是否出现维护诊断手册描述的Dump设备。此功能不等于已能接收或解码Dump。

- `CONFIG_VOICE_ML307_USB_OBSERVER`默认关闭，正常固件不包含该源文件。
- ESP32-S3原生USB D−为GPIO19、D+为GPIO20；电脑控制台继续用CH343 UART0。
- 专用调试配置必须选择`CONFIG_ESP_CONSOLE_SECONDARY_NONE=y`，避免USB Serial/JTAG副控制台占用内部USB PHY。
- 调试配置的USB控制传输上限为4096字节，兼容实测ML307C多接口配置描述符。
- 原通话仍走GPIO17/18，921600波特率。观察器不发送USB AT、厂商诊断激活命令或Bulk OUT，不承载媒体，不调用模组重启。
- 日志仅在USB端口状态变化或设备枚举时输出，任务优先级2；不会持续打印诊断原始数据。
- 观察器未申领USB AT或诊断接口，也没有待取消的Bulk请求；可在设备断开后关闭句柄并观察下一个设备。
- 已通过独立demo设置并读回`AT+MDUMPCFG=1`。此调试版不重复设置，也不能据此保证任何断电、看门狗或硬件复位都会产生Dump。

专用配置与编译结果保存在项目`build/`，不覆盖发布目录里的正常固件。刷机仅更新当前实物OTA0应用，保存完整Flash备份，校验应用和应用区外区域。日志、Dump及可能含凭据的数据只保存在本地。

测试流程：先确认USB正常`2ecc:3012`枚举和UART/MQTT通话就绪，再运行短通话复现。如果出现新的USB设备，保留现场并依据真实端点评估接收方案；如果仍是原设备或没有Dump，不能凭USB断开单独判断崩溃或供电原因。此阶段不计入正式40轮。
