# 商家资料适用范围与ML307C-DL核对

该资料包包含多型号通用手册，不应把整个包说成仅适用于ML307R；各手册的适用型号仍需分别核对。本版本尚未列ML307C，不能仅凭“ML307系列”标题推断覆盖C系列。

ML307C-DL仍可作为低成本USB替代候选。另查到的[ML307C产品规格表](https://atta.szlcsc.com/upload/public/pdf/source/20250520/C8D82017131DF28894979DE03B6B48F2.pdf)列出C-DL-CN USB2.0、RNDIS、ECM、3.4–4.5V典型3.8V；这仅确认所列型号功能规格，不能证明商家出售开发板的USB引出、实际AT固件、ESP32驱动兼容或诊断工具支持。

现有ML307R USB候选和109焊盘PCB维持不变。若改用C-DL，需核对所售完整型号及原厂AT固件、USB描述符/拨号初始化、UART电压及引脚、供电、实际焊盘和匹配的内部诊断工具。C系列的验证另建批次，不加入R系列40轮实机结果。

源PDF文件摘要清单在本机build/ml307-vendor-docs/sources.json；ZIP/全文核对记录与渲染页在build/ml307c-reference。核对期间未向健康通话发送AT配置、重启或模式切换命令。
